## Model research (done without Tavily — plan limit hit)
- `tavily_*` search returned nothing usable; porsche.com and caranddriver
  returned empty bodies to curl. Wikipedia API worked.
- Used `action=parse&prop=wikitext` on `Porsche_911_(992)` for the infobox and
  `Porsche_911_GT3` for variant rows. 992: 4519-4535 x 1852-1900 x
  1289-1303 mm, wheelbase 2450 mm. GT3 992 row: 178.94 in = 4545 mm.
- Chose **Porsche 911 GT3 RS (992.1, Aug 2022)**: swan-neck wing, 860 kg
  downforce @285 km/h, roof shark fin. Final model uses 4572 x 1900 x 1322 mm
  and 2457 mm wheelbase. GT3 RS-specific length/width were **not** available
  from a primary source, so the numbers are the 992 GT3 figure scaled to the
  documented RS width — say so if the user asks for a citation.

## Sesi lanjutan — hidupkan link + masukkan car-chase ke Studio

### Link sempat mati
`ps` kosong dan URL publik menjawab `Bad Gateway`: sandbox mematikan proses latar
tanpa peringatan. `./scripts/serve.sh 12000` menghidupkan API + worker lagi, lalu
`scripts/keepalive.sh` (interval 30 s) supaya tidak mati lagi. Jangan simpulkan
"situsnya rusak" sebelum mengecek `ps` + `/api/health`.

### Memasukkan video ke Perpustakaan
Perpustakaan sepenuhnya statis dari `studio/src/data/rendered.ts`; berkasnya
dilayani dari `video/<slug>.mp4` + `thumb/<slug>.jpg`. Langkahnya:
1. salin mp4 ke `netlify-site/video/`, buat thumb dari frame paling terang
2. tambah entri di `RECORDED` dengan `qa: 'render-3d'`
3. `npm run build:studio`, `npm test`, commit, push (Pages deploy otomatis)

Yang penting: `seedFrom` harus melewati `render-3d`, kalau tidak video ini muncul
sebagai proyek demo dengan "9 tahap selesai" — riwayat kerja yang tidak ada.

### Angka thumbnail
Menebak kecerahan dari ukuran berkas PNG menyesatkan (semua 15-20 KB). Yang
benar: `ffprobe -f lavfi "movie=...:seek_point=T,signalstats"` dan ambil YAVG.
t=10 paling terang (84,8); t=34/41 hanya 42,9. Frame gelap menghasilkan thumb
10 KB yang tampak kosong di kartu.
