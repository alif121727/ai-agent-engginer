## Model research (done without Tavily — plan limit hit)
- `tavily_*` search returned nothing usable; porsche.com and caranddriver
  returned empty bodies to curl. Wikipedia API worked.
- Used `action=parse&prop=wikitext` on `Porsche_911_(992)` for the infobox and
  `Porsche_911_GT3` for variant rows. 992: 4519-4535 x 1852-1900 x
  1289-1303 mm, wheelbase 2450 mm. GT3 992 row: 178.94 in = 4545 mm.
- Chose **Porsche 911 GT3 RS (992.1, Aug 2022)**: swan-neck wing, 860 kg
  downforce @285 km/h, roof shark fin. Final model uses 4572 x 1900 x 1322 mm
  and 2457 mm wheelbase. GT3 RS-specific length/width were **not** available
  from a primary source, so the numbers are the 992 GT3 figure scaled to the
  documented RS width — say so if the user asks for a citation.
