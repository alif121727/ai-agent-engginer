
## Audio 30 dtk bisu (root cause) — selesai
- Dua `loudnorm` yang bertemu di `amix` membuat ffmpeg 7.x abort
  `Assertion best_input >= 0 failed` (ffmpeg_filter.c:2122) — HANYA pada
  durasi panjang (30 dtk); 3 dtk lolos, jadi tes mux lama tidak menangkapnya.
- Fix: `norm()` = `loudnorm=...,aresample=48000` per input di `src/render/audio.ts`.
- Regresi ada di `tests/run.ts` ("campuran mesin + musik 30 dtk").

## Deep-link `#/proyek/:id` "tidak ditemukan"
- Penyebab: `refresh()` baru jalan setelah sesi siap, jadi render pertama
  melihat `projects` kosong + `loadingProjects` false.
- Fix: flag `projectsLoaded` di `studio/src/state/store.tsx`, dipakai
  `ProjectDetail.tsx` untuk menahan empty-state sampai daftar pernah dimuat.
- Catatan: mengganti hash saja TIDAK memuat ulang bundel; pakai `?cb=1`
  atau hard reload saat menguji UI yang baru dibangun.

## QA menolak "scene terlalu mirip" = foto terulang, bukan bug QA

  di depan daftar, padahal referenceImage itu SALAH SATU foto di daftar `own`.
  Rotasi bergeser 1 -> scene 0 dan 1 memakai file identik.
