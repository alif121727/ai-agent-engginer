# 2026-11-25

## Template mobil (cartpl) tampil di studio

- `GET /api/car-templates` sengaja didaftarkan **sebelum** `app.use('/api', requireAuth)`
  supaya halaman Garasi bisa menampilkan katalog sebelum login. Kalau endpoint
  dipindah ke bawah middleware itu, panel hilang tanpa pesan galat (fetch 401 →
  komponen `return null`).
- `listCarTemplates()` di `src/core/car-templates.ts` mengikuti rantai
  `meta.extends` sendiri karena validasi/render tetap milik Python. Dimensi
  diturunkan: panjang = overhang_front + wheelbase + overhang_rear,
  lebar = body_width_max × 2.
- Pratinjau: `python3 -m cartpl render-preview --all -o public/cartpl-preview --size 512`.
  Verifikasi isi gambar dengan hitung cakupan piksel non-latar (14–21% berarti
  mobil benar-benar ada; bidang kosong akan ~0%).

## Cara membuktikan mobil hero terlihat di car-chase

Perbandingan template vs GT3 RS saja tidak cukup (selisih bisa datang dari
latar). Yang meyakinkan: warnai `colors.body_base` jadi merah terang
(`[0.85,0.05,0.05]`), render satu frame, lalu hitung piksel merah. Hasil t=3:
15.5% frame, rasio bbox 2.53, puncak baris 309/720 dan kolom 674/1280 →
siluet mobil di tengah frame. Diff biasa: 77.633 piksel / 12.8%.

Catatan: body default `_base.json` = `[0.02,0.02,0.025]` (hampir hitam), jadi
frame normal terlihat gelap. Itu warna spec, bukan bug render.
